# 1,000 × $1 Experiment

"Can the internet help one ordinary person get 1,000 different people to contribute at least $1?"

## Tech Stack
- **Frontend & API:** Next.js (App Router)
- **Analytics:** PostHog
- **Database / Source of Truth:** Supabase (PostgreSQL)
- **Payments:** PayPal API

## Setup Local
1. Clona el repositorio.
2. Instala Node.js y corre `npm install`.
3. Copia el archivo `.env.example` a `.env.local` e introduce tus credenciales de Sandbox.
4. Ejecuta `npm run dev`.
5. Abre `http://localhost:3000`.
